## Descrição da Aplicação
Uma aplicação web colaborativa para postar avisos do curso. O sistema exibirá também a previsão do tempo atual para a cidade configurada, consumindo a API pública Open-Meteo (não requer chave).

## Tecnologias
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js com Express
- **Banco de Dados:** SQLite
- **Testes:** Jest
- **CI/CD:** GitHub Actions
- **Deploy:** Docker
